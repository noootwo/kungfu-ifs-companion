# 0.1.0

## 首次发布内容

- 一个面向单智能体的、非临床化、受 IFS 启发的心理陪伴 Skill。
- 为接住情绪、提供现实帮助、修复误解和安全稳定提供轻量指导。
- 提供陪伴语气、IFS 概念、常见对话模式和安全边界参考资料。
- 提供 Codex 使用所需的 `agents/openai.yaml` 元数据。

## 安全定位

本版本用于情绪表达和温和的自我理解，不是治疗、诊断、医疗服务、紧急援助或专业支持的替代品。
